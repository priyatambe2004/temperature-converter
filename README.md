# Veda Internship – Task 5: Temperature Converter

A simple and responsive **Temperature Converter** built using **HTML5, CSS3, and JavaScript**.

## 📌 About the Project

This project allows users to convert temperatures between:

* Celsius
* Fahrenheit
* Kelvin

The converter performs calculations dynamically and provides validation for invalid inputs.

This project was created as **Task 5** of my Web Development Internship to practice JavaScript functions, form inputs, calculations, input events, and DOM manipulation.

## ✨ Features

* Convert Celsius to Fahrenheit and Kelvin
* Convert Fahrenheit to Celsius and Kelvin
* Convert Kelvin to Celsius and Fahrenheit
* Input validation for invalid values
* Live conversion using input events
* Simple and responsive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript



## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a temperature and select the required conversion.
5. The converted temperature will be displayed automatically.

## 📐 Conversion Formulas

### Celsius to Fahrenheit

`°F = (°C × 9/5) + 32`

### Fahrenheit to Celsius

`°C = (°F − 32) × 5/9`

### Celsius to Kelvin

`K = °C + 273.15`

### Kelvin to Celsius

`°C = K − 273.15`
